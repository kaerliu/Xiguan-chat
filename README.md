# 吸管 AI 接待交互原型

这是一个前端单页原型，覆盖：

- AI 接待创建、配置、调试与发布
- 会话查看、人工接管与回复
- 访客线索和 Q&A 洞察
- 企业切换、成员、套餐与个人设置

## 运行

安装 Node.js 后，在项目目录运行（无需安装第三方依赖）：

```bash
npm run dev
```

然后访问 `http://127.0.0.1:8123`。

请使用该本地服务编辑「产品逻辑」。保存会直接更新仓库中的 `product-logic.md`，因此可以随其他代码一起提交。在线部署只读取该文件并以只读方式展示，不会把修改保存在访客浏览器中。

首次打开会显示创建引导。完成后状态会保存在浏览器本地；也可以从左下角账号菜单选择“重新体验创建引导”。

## 智能体搭建页的文件分工

「角色与提示词 / 能力 / 知识库 / 外观」四页按控制台源码还原，代码拆在这几个文件里（`index.html` 按下面的顺序加载）：

- `agent-capabilities.js`：能力列表与每个能力的配置详情、右侧演示（留资表单、转人工、资料交付、主动弹窗、沉默跟进，以及测评式营销、留资弹窗、推荐消息、MCP 调用）。
- `agent-toolbar.js`：官网侧边工具栏的模板、按钮编辑器、弹出面板预览和图片上传处理。
- `agent-config.js`：草稿状态（保存 / 发布 / 放弃）、角色与提示词、知识库、外观，以及上面两个文件的事件接入。
- `product-logic.html`：产品逻辑记录页；本地环境可编辑，线上环境自动只读。
- `product-logic.md`：产品逻辑的唯一内容源，随代码提交和部署。
- `dev-server.js`：零依赖本地服务，静态托管原型并将产品逻辑保存回仓库文件。
- `assets/xiguan-logo-fill.png`：对话窗口底部「吸管 提供技术支持」的图标。

概览与五个配置页共用同一套顶部草稿状态和发布操作；角色、能力、知识库、外观与渠道配置保存在浏览器本地（`xiguan-agent-config-draft` / `xiguan-agent-config-published`），清空这两个键即可恢复默认。
