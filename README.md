# 吸管 AI 接待交互原型

这是一个前端单页原型，覆盖：

- AI 接待创建、配置、调试与发布
- 会话查看、人工接管与回复
- 访客线索和 Q&A 洞察
- 企业切换、成员、套餐与个人设置

## 运行

安装 Node.js 后，在项目目录运行（无需安装第三方依赖）：

```bash
npm run dev
```

然后访问 `http://127.0.0.1:8124`。

请使用该本地服务编辑「产品逻辑」。保存会直接更新仓库中的 `product-logic.md`，因此可以随其他代码一起提交。在线部署只读取该文件并以只读方式展示，不会把修改保存在访客浏览器中。

首次打开会显示官网入口。输入官网后先模拟扫码授权，再进入工作台解析；直接注册则在工作台输入官网。已创建助手的回访用户直接进入工作台。

## 智能体搭建页的文件分工

「角色与提示词 / 能力 / 知识库 / 外观」四页按控制台源码还原，代码拆在这几个文件里（`index.html` 按下面的顺序加载）：

- `agent-capabilities.js`：能力列表与每个能力的配置详情、右侧演示（留资表单、转人工、资料交付、主动弹窗、沉默跟进，以及测评式营销、留资弹窗、推荐消息、MCP 调用）。
- `agent-toolbar.js`：官网侧边工具栏的模板、按钮编辑器、弹出面板预览和图片上传处理。
- `agent-config.js`：草稿状态（保存 / 发布 / 放弃）、角色与提示词、访客对话组件，以及配置事件接入。
- `agent-appearance.js`：上游完整外观配置与桌面 / 手机 / 对话预览。
- `product-logic.html`：产品逻辑记录页；本地环境可编辑，线上环境自动只读。
- `product-logic.md`：产品逻辑的唯一内容源，随代码提交和部署。
- `dev-server.js`：零依赖本地服务，静态托管原型并将产品逻辑保存回仓库文件。
- `assets/xiguan-logo-fill.png`：对话窗口底部「吸管 提供技术支持」的图标。

概览与五个配置页共用同一套顶部草稿状态和发布操作；角色、能力、知识库、外观与渠道配置保存在浏览器本地（`xiguan-agent-config-draft` / `xiguan-agent-config-published`），清空这两个键即可恢复默认。

- [产品界面](http://127.0.0.1:8124/index.html)：已配置助手的用户直接进入工作台。
- [输入官网流程](http://127.0.0.1:8124/index.html?flow=new)：输入官网 → 扫码体验登录 → 原版工作台解析 → 官网与助手预览。
- [直接注册后的流程](http://127.0.0.1:8124/index.html?flow=direct)：在原版工作台输入官网，自动解析并生成默认配置。

概览保留原版的配置、运行轨迹和提示词 / 知识库 / 能力 / 外观分类；仅在首次完成时增加可关闭的就绪提示和大尺寸开始试用按钮，点击切换到对话窗口。调试台直接使用原版官网浏览器、对话窗口、输入区、消息和快捷按钮，在原预留操作位增加分享和放大。各配置页、保存草稿和发布弹窗均复用原实现。

`onboarding.js` 只接入首次路径、扫码承接、解析状态、就绪反馈、只读分享和转场。解析弹窗先收拢到调试台的网址框，落位后填入网址，再露出提前加载的官网。真实官网 iframe 不移除、不重建；移动的是弹窗本身。官网右下角对话窗口默认收起，点击入口后才展开。输入官网弹窗不展示抓取范围和页数说明。`onboarding.css` 仅定义 onboarding 自身样式和新增状态，不覆盖原版工作台与访客组件。上一版入口文件保存在 `versions/onboarding-v4/`。

原型边界：扫码通过体验登录按钮模拟成功；二维码是示意图。官网 iframe 为真实地址；官网解析、最多 5 页数据、主题色和问答仍用本地示例。任意未知域名会说明尚未接入真实解析服务，不假装识别其业务。分享将名称、颜色、欢迎语和业务摘要写入 URL 快照，分享页没有配置入口；本地链接仅当前设备可访问。部署保留在原渠道页。

验证：语法检查与 `git diff --check`；原始组件文件与来源逐文件比对；Chrome 检查原版配置分类、运行轨迹、对话试问、官网预览、分享、官网输入弹窗及解析自动承接。生产授权、官网抓取、检索问答和服务端分享权限仍是后端接入范围。

本轮仅收敛新增 onboarding：就绪区使用白底细边框，去掉勾选图标与绿色整块背景；标题改为官网资料已导入，保留 40px 高开始试用按钮；弹窗落到网址框的转场缩短为 420ms，官网以 160ms 淡入，不再闪色。右下角对话默认收起，输入官网不展示抓取范围说明。
